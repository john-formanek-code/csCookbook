# java-cviceni-druhak (High/2)

2nd-year ("druhak") Java exercises, migrated from the legacy `td/src/druhak/`
dump. `school/High/2/` previously had no programming subfolder (it only held
matika/cestina/office-skills material), so this is a new addition — same
course track as `school/High/3/java-cviceni/`, one year earlier.

## Contents

- `basics/` — hello-world, simple prints, first loops/patterns (stars,
  triangles).
- `arrays-lists/` — arrays, `ArrayList`, sequences.
- `math/` — number theory exercises (primes, divisibility, interest,
  narcissistic numbers, right triangles).
- `games-logic/` — guessing games, dice, FizzBuzz, tic-tac-toe.
- `input-output/` — `Scanner`-based console I/O practice.
- `strings/` — Morse code, Pig Latin, string exercises.
- `misc/` — 2 empty `.Rhistory` leftovers (harmless, not Java-related).

## Naming convention

Original Czech exercise file names kept as-is (course-assigned).
